# Skyhurst Studios — Fine Art For The Discerning Nerd

A luxury, high-performance web platform for **Skyhurst Studios**, featuring fantasy & anime illustration, concept art, sequential art, convention schedules, and custom commission ordering.

Created by **Gary Laib** & **Chris Wilhelm**.

---

## ✨ Features

- **Next.js 16 (App Router)** & **React 19**
- **Lenis Smooth Scrolling** & kinetic interactive physics
- **Responsive Luxury Design System** (Dark Slate theme, Syne, Playfair Display & Space Grotesk typography)
- **Interactive Art Gallery & Filters** (Featured, Fantasy, Anime, Sci-Fi, Concept Art)
- **Dynamic Commission Customizer & Order Flow**
- **Artist Spotlights** (Gary Laib & Chris Wilhelm)
- **Full Convention Tour & Live Schedule**
- **Client & Partner Marquee Showcase**
- **Fully SEO Optimized & Social OpenGraph Ready**

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## 🌐 Deployment

Optimized for deployment on [Vercel](https://vercel.com):
- **Framework Preset**: Next.js
- **Node.js Version**: 20.x
- **Build Command**: `next build`
- **Output Directory**: `.next` (default)
